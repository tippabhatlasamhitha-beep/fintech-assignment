# SQL Business Analysis

## Query 1
Transaction counts were grouped by transaction status.

## Query 2
Total successful GMV was calculated merchant-wise.

## Query 3
Top merchants were identified using successful GMV values.

## Query 4
Daily GMV and successful transaction counts were analyzed.

## Query 5
Merchants with chargeback ratio above 1% were identified.

## Query 6
No region satisfied both conditions of average risk score above 50 and transaction count above 20.

## Query 7
One user had 3 or more failed/chargeback transactions on the same day.

## Query 8
Chargeback count, affected users, and total chargeback amount were analyzed.
